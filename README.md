# familyassistant

Self-hosted family assistant: a modular, security-focused server with a PWA client for household and family tasks (shopping lists, calendar, backups, photo albums, smart home).

## Status

Concept phase. The overall concept (in German) is in [docs/concept/overall-concept.md](docs/concept/overall-concept.md). Implementation starts only after the concept is approved.

## Conventions

- All code, identifiers and comments are in English.
- The user interface is multilingual (German and English at launch).
